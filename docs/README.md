# Документация XPlain

XPlain — расширение VS Code / Cursor для объяснения кода с помощью вашей агентской системы на базе LLM.
Пользователь собирает блоки кода в контекст, добавляет вопрос и шаблон, подтверждает отправку, а ответ
агента сохраняется в проекте и привязывается к коду через CodeLens.
